FEATURED PROJECT

FULL-STACK OBSERVABILITY

NASA NEO Observability Lab

End-to-end observability lab built around a FastAPI application consuming NASA's Near Earth Object API.

The full observability stack combines Grafana, Prometheus, Loki and Tempo, with OpenTelemetry providing instrumentation, collection and telemetry correlation.

  • Metrics and RED Method monitoring with Prometheus
  • Structured application logs with Loki
  • Distributed tracing and TraceID correlation with Tempo
  • Unified investigation experience in Grafana
  • Controlled latency and HTTP 500 incident simulation
  • Dockerized and reproducible environment
